Build & publish

From idea to a link you can share.

Publish a report or file in seconds, or build a small app with a coding agent. Everything you publish is yours to manage and share.

Steps

1

Install the Hex tool

Download the installer for your computer and run the command below. It installs Hex and connects it to {{.Platform}}; there is nothing to configure.

{{if .InstallersAvailable}}
Download installer 
bash "$HOME/Downloads/install-hex-linux.sh"

Open a terminal, paste the command and press Enter. Already installed? Run hex update.

{{else}}

Your platform operator needs to configure connection settings before installers are available.

{{end}}
2

Share a file or folder

Publish anything to a private link that only you can open:

hex publish ./report.pdf -n "Q3 report"

Hex prints the link. Share it with colleagues from Your sites, or straight away with --with user:name@company.com.

3

Build an app with your coding agent

Start a project, then describe the app you want to your agent: 

hex init my-app

Hex adds instructions your agent understands, including how to store data and who may use it. When it is ready, publish it from the project folder: 

hex publish

The first time, Hex opens your company sign-in in the browser. The first person to publish a name owns it.
