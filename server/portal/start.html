Build & publish

From idea to a link you can share.

Publish a report or file in seconds, or build a small app with a coding agent. Everything you publish is yours to manage and share.

Steps

1

Install the Hex tool

Download the installer for your computer and run the command below. It installs Hex, connects it to {{.Platform}}, and sets up Claude Code, Codex and OpenCode to use Hex for new apps.

{{if .InstallersAvailable}}
Download installer 
bash "$HOME/Downloads/install-hex-linux.sh"

Open a terminal, paste the command and press Enter. Already installed before assistant setup was available? Run hex update, then hex agents install once. The connected Hex MCP server checks for updates automatically; new versions take effect in a new session.

{{else}}

Your platform operator needs to configure connection settings before installers are available.

{{end}}
2

Share a file or folder

Publish anything to a private link that only you can open:

hex publish ./report.pdf -n "Q3 report"

Hex prints the link. Share it with colleagues from Your sites, or straight away with --with user:<identity-id>.

3

Build an app with your coding agent

Start a new Claude Code, Codex or OpenCode session in your app folder and describe what you want. Hex is already configured as the default platform for new web apps: 

Build an equipment tracker for our team and publish it.

Your assistant creates the project, builds and tests the app, then publishes it through Hex and gives you a link. It needs file editing and build tools; ordinary desktop chat alone is not enough.

If sign-in is needed, your assistant starts it for you. Complete company sign-in and MFA in your browser, then return to the conversation. Hex remembers your session.

Using another coding harness? Run hex agents --help for setup options. Cowork needs a separately configured local MCP connection and a shared project folder. The first person to publish a name owns it.
