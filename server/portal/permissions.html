2 · APP PERMISSIONS

Who can do what?

Each column is a site-owned permission group. Click its name to edit what it allows.

Defaults apply to everyone admitted. Add rows only for people or directory groups needing extra permissions. Permissions add together; an unchecked box cannot deny a default or another group's access.

The table shows default and explicit assignments, not an effective-access calculation. Other directory memberships and direct resource rules may also grant access. Existing owner permissions are preserved; new groups offer explicit owner assignments.

Other resource rules and page restrictions

Rules outside the permission groups are preserved. They can independently allow access; unticking a group does not revoke these rules.
