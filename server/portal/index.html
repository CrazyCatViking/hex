Install and connect

Download your platform's installer in this browser, then run the command below. It installs the latest CLI and connects it to this platform automatically.

{{if .InstallersAvailable}}

Download installer

02

Start a project

Open a new terminal and initialize your app:

hex init my-app

Open the project in your editor. Hex installs an agent skill that explains the platform and the @crazycatviking/hex npm client.

03

Build, then share

Ask your agent to build the app. Once the build is ready in dist, publish from your project directory: 

hex publish

For Azure Files publishing, install AzCopy and use hex login to sign in to storage when needed.

Add a title, description, and author in hex.json. Set "discoverable": false to keep the app out of this overview. Change it to true and republish when it is ready to show. Hiding a listing does not restrict access to its URL.
